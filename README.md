# Sakshit Fanbase

A fan site for Sakshit, built as a simple static website with HTML and CSS.

## Pages

- `index.html` - the home page.
- `sakshit.html` - the main page about Sakshit.
- `result.html` - the results page.
- `style.css` - the shared stylesheet.

## Running

No build step is needed. Open `index.html` in a browser.

## Hosting

The site is hosted on Vercel.
